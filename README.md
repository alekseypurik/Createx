Пет-проект. Создан в учебных целях.

Createx Project — адаптивный лендинг образовательной платформы с полным набором интерактивных секций: о компании, направления обучения, программы, блог, сертификаты и многое другое.

✨ Возможности
Модульная SCSS-архитектура

Полная адаптивность — mobile, tablet, desktop

Слайдеры Slick — карусели для отзывов, блога, компаний

Модальные окна Fancyapps — галереи, видео, попапы

Быстрая сборка — Vite

Миксины и переменные — переиспользуемые стили

🛠 Технологии
HTML5 — семантическая разметка

SCSS (Sass) — модульная стилизация (БЭМ-нейминг)

JavaScript (ES6+) — интерактивность

Vite — сборка и dev-сервер

jQuery — DOM-манипуляции и работа с плагинами

Slick Carousel — слайдеры

Fancyapps UI — модальные окна и галереи

🚀 Запуск проекта
1. Установить зависимости
bash
npm install
2. Запустить dev-сервер
bash
npm run dev
